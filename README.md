# Házirend – háztartási teendők kezelője

Webalkalmazás az átlagos háztartás ismétlődő feladataihoz: számlabefizetés,
gázóra / villanyóra / vízóra diktálás, olajcsere, műszaki vizsga, kazán
karbantartás és hasonlók.

- Bármilyen ismétlődő teendő felvihető, kész sablonokból is.
- Rugalmas ismétlődés: fix naptári (RRULE), időablak, elvégzéstől számított,
  használat-alapú (km) – kombinálható („15 000 km vagy 1 év, ami előbb”).
- Magyar ünnepnapok és munkaszüneti napok kezelése.
- Kétirányú Google Naptár szinkronizáció, iCal feed más naptárakhoz.
- Több tagú háztartás, felelősökkel, értesítésekkel.

A részletes terv: [docs/DESIGN.md](docs/DESIGN.md)

Állapot: tervezési fázis.
